# Restaurant Health Dashboard

Feature ID: `PH2D-PRODUCTION-001`

The Restaurant Health Dashboard is the first real Food Gedi plugin implemented on the official SDK. It is disabled by default with `NEXT_PUBLIC_ENABLE_RESTAURANT_HEALTH_DASHBOARD=false`.

The plugin validates SDK-only use of context, storage, router, UI extension points, assets, services, hooks, logger, events, runtime, diagnostics, permissions, config, lifecycle, API, and manifest metadata.

No Customer, Owner, Kitchen, POS, Admin, QR, payment, auth, Firestore, repository, realtime, or business workflow module is imported.
