# Roadmap

Last updated: 2026-06-22

## Phase 1 - Owner Enterprise Foundations

- Completed: Offer Consolidation.
- Completed: Centralized Menu Pricing Engine.
- Next: Staff & Access restructure with Staff, User Accounts, Roles, Activity Logs, and View Switching tabs.

## Phase 2 - Operations Modes

- Owner Mode: full access.
- Waiter Mode: dashboard, Order Desk, orders, tables, customers, Kitchen Operations Center.
- Kitchen Mode: kitchen dashboard and Kitchen Operations Center.

## Phase 3 - Kitchen Operations Center

- KPI cards for pending, preparing, ready, delivered today, average prep time, delayed, and priority orders.
- Responsive Kanban board with received, preparing, ready, delivered.
- Full-screen TV mode with touch-friendly actions.

## Phase 4 - Order Desk

- Rename POS to Order Desk.
- Mobile-first waiter flow with bottom navigation, menu grid, cart drawer, KOT, billing, hold, save, and cancel actions.

## Phase 5 - Controls

- Printer profiles and routing.
- Audit logs.
- Owner-password verification for protected view switching.
