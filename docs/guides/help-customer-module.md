# Customer Module Help

## Overview
The Customer Module delivers the public food ordering experience. It is designed as a premium, mobile-first commerce surface with discovery, restaurant browsing, ordering, offers, and order tracking.

## Total Screens: 8

### 1. Homepage (`/`)
- Main feature: image-led hero with high-visibility restaurant and offer promotion.
- Includes: featured restaurants, trending dishes, cuisine categories, offer carousel, and fast delivery messaging.
- Benefit: improves first impression and drives quick order action.

### 2. Search / Restaurant Listing (`/restaurants`)
- Main feature: destination-grade search with rich hero and filter chips.
- Includes: large search input, premium restaurant cards, location/address picker, recent delivery addresses, and cuisine filters.
- Benefit: lets customers find restaurants quickly with a focused search experience.

### 3. Restaurant Detail (`/restaurant/[slug]`)
- Main feature: premium restaurant landing page with social proof and sticky start-order CTA.
- Includes: restaurant hero image, ratings, hours, contact actions, offers, popular items, and menu access.
- Benefit: gives customers confidence and easy access to the restaurant menu.

### 4. Restaurant Menu Flow (`/restaurant/[slug]/menu`)
- Main feature: sticky menu search and category tabs for seamless browsing.
- Includes: filter chips, category and cuisine navigation, item lists, and persistent cart access.
- Benefit: keeps browsing fast and prevents the customer from losing context while ordering.

### 5. Product Detail / Item Page (`/restaurant/[slug]/item/[itemId]`)
- Main feature: large food imagery and fast order conversion from a single item view.
- Includes: rating, price, offer state, customization controls, add-to-cart, checkout CTA, and WhatsApp dish CTA.
- Benefit: converts social or deep-link traffic directly into a checkout-ready item experience.

### 6. Checkout (`/checkout`)
- Main feature: visually simplified payment flow with sticky mobile action.
- Includes: payment options (UPI, Razorpay, COD), delivery details validation, order summary, offer code application, and confirmation.
- Benefit: reduces friction at the final purchase step.

### 7. Offers (`/offers`)
- Main feature: dedicated offer browsing screen.
- Includes: public offers, active promo details, and use-offer CTA.
- Benefit: highlights discounts and increases order conversion.

### 8. Order Tracking / Confirmation (`/order/[id]` or `/track-order`)
- Main feature: generated order timeline and status tracking.
- Includes: order status updates, estimated delivery progress, and receipt links.
- Benefit: keeps customers informed after checkout.

## Core Feature Highlights
- Premium mobile-first UI with dedicated customer theme.
- Rich discovery and search optimized for foodie behavior.
- Instagram commerce support with deep links and auto-applied offers.
- Sticky mobile cart and checkout controls.
- Public data separation from owner/internal fields.
