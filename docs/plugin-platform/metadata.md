# Plugin Metadata

Every plugin exposes a metadata contract with id, name, display name, description, publisher, version, license, category, dependency lists, permissions, feature flag, app/runtime compatibility, platform/module support, entry point, documentation links, bundle/install size, checksum, signature, health, and status.

Validation rejects duplicate ids, duplicate names, duplicate feature flags, missing versions, missing permissions, missing entry points, and invalid semantic versions.
