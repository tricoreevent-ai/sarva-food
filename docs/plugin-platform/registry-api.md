# Registry API

Primary APIs:

- `getEnterprisePluginRegistry()`
- `register(metadata)`
- `unregister(id)`
- `markValidated(id)`
- `markInitialized(id)`
- `enable(id)`
- `run(id)`
- `disable(id)`
- `suspend(id)`
- `resume(id)`
- `destroy(id)`
- `get(id)`
- `getState(id)`
- `getMetadata(id)`
- `lookupByFlag(flag)`
